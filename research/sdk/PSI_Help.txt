Introduction
 Welcome to Pakon Digital Imaging!
The PSI software is designed specifically for the Pakon F-235 and F-135 Digital
Scanners. We hope you find this manual useful in learning how to use the Pakon
scanner and PSI Interface Software.

This manual will help you learn how to fully utilize the potential of the scanner
and harness its abilities. It is divided into small sections to help you both learn
quickly and use it as a reference in learning more and more about the capabilities
of your Pakon scanner!

F-135 LED's




Power LED
Off - there is no power to the scanner.
Green - the scanner is on.




8
                                                                   How to Guides



Status LED

Solid Green - The scanner is ready.
Blinking Green - The scanner is scanning
Blinking Yellow - The scanner is unable to scan at the moment
Blinking Red - The scanner is reporting an error.
Off - The scanner is not functioning properly.

Film LED

Off – there is no film in the scanner and there is no need to do anything
Blinking Green – Insert film to be scanned
Solid Green – Scanner is scanning the film in the scanner – do not insert film
Blinking Yellow – Remove film from the scanner

How to Customize Logos
There are two logos that are used in the PSI program. They can be customized
to reflect the name of the company or organization creating output materials.

Logo_CD.bmp




This is the logo printed onto Pakon CD's. The logo file is a bitmap and is 1083 x
661 pixels in dimension.

Logo_Master.bmp




                                                                               17
PSI




This is the primary logo file, and is used for all printed output with the exception
of Pakon CD's. This logo file is also a bitmap and is 1110 x 398 pixels in
dimension.

Custom Logo's

To create custom logos, create files with the specified dimensions in an image
editing software such as Microsoft Paint, Adobe Photoshop, Paint Shop Pro, etc.


Save these files to the following directory:

C:\Program Files\Pakon\PSI\IQ\Logos

It is important to keep the file names as they are shown above. PSI looks for
these files when creating the output, and will only look for these files.

File Name Prefix

This is the name that the selected images will be saved as. Inserting "ROLLID"
will put the order's roll ID in the name of the saved file. Inserting "COUNT" will
add the count of each picture within the order. For example, the first image in an
order will be numbered "01" even if it has an index number of 04. Typing in
anything else will add that as a prefix to the file name.

For example, if this is in the "File name prefix" box, this is how images will be
saved to disk, assuming a roll ID of 5625:

"COUNT_ROLLID_Pakon_"

An image that would otherwise be named AAA004 would become
"01_5625_Pakon_AAA004.jpg"

The next image would be named "02_5625_Pakon_AAA005.jpg"

IQueue Program
IQueue is an independent program from PSI, though it is dependent on PSI for
any output. IQueue must load along with PSI for it to operate properly.
 Therefore, there is an option in PSI to force IQueue to load with PSI.

IQueue waits to receive a signal from PSI that there are images pending in the
queue for IQueue to process and output. IQueue has three states that it
operates in.

IQueue allows the operator to assign multiple printers with multiple tasks. For
example, an ink jet printer is required for sleeves and CD labels. But the
operator can also set up IQueue to use a dye-sub printer for 4x6 prints and a
digital mini-lab for 8x10's.

IQueue has three modes of operation:

Waiting - IQueue is waiting for jobs from PSI to begin.

Running - IQueue is processing a job or jobs.

Stopped - IQueue has stopped, or put all orders on hold, due to the operator
having stopped it.

PSI

Jobs are sent to IQueue from PSI. A job consists of an Internet, CD-R, Sleeve,
Index, or Single request.

Jobs can sit in pending if IQueue is stopped. Otherwise they will move to
"Running Jobs" as any previous job completes.

Lines in Scans
Lines in scans can be caused two ways. The first is that the scanner needs to be
calibrated. The temperature of the lamp can vary and re-calibrating the scanner
ensures the highest image reproduction. Run the "Gain Test" to calibrate the
scanner.

The scanner illumination could also be dirty and require cleaning.

Error Code 3013
The N:\ hard drive is bad. Replace the second hard drive that is used for the
scanner buffer drive.

Scanner Stops Prematurely
Run the "Gain Test" in the Calibration Wizard.

Motor doesn't stop after scanning
If the scanner motor does not stop after a roll of film has finished scanning,
manually hit the "Stop" button. To fix the problem, run the Gain Test.



                                                                                 149
PSI


DX Codes Not Being Read
Run the "Track Test" in the Calibration Wizard.

A dirty film track will also cause DX codes to not be read properly. Clean it
regularly to ensure proper DX code reporting.

Hardware Fault Codes
Hardware fault codes are usually one of two varieties. Hardware fault codes will
be reported if the film was inserted improperly. They will also be reported for
hardware failures.

Cleaning the fan filter regularly will ensure that the scanner does not overheat
and turn off the lamp to avoid damaging the scanner.

Cleaning the illumination bar regularly will also ensure that fault codes related to
a dirty illumination bar not be reported.


Stretched Images
A dirty film track will cause the film inside the scanner to not travel through the
film path at the proper speed and will caused images to appear stretched.

Clean the film track regularly to avoid this problem.

Error Log Files
There are error log files located on the computer that will be helpful when
determining any problems with an F-235 scanner. These files are located in
C:\Program Files\Pakon\TLA Com Server. The files are named
"PakonErrorLog." Please include these files with any email correspondence with
your technical support representative.

Images Out of Focus
Run the "Focus Test" in the Calibration Wizard to improve the focus of the F-235
Scanner.

Lamp Warm-Up Time (F-235 Only)
The lamp warm-up time cannot be reduced the first time the scanner is turned
on. The lamp warms up to ensure that image quality is satisfactory. However,

of inactivity. This can be disabled.

Under "Setup" -> "General" either disable the lamp saver, or increase the time
allowed before the lamp turns off to 9999 to ensure it does not turn off.

Noritsu 2611
The Noritsu 2611 mini-lab can be used as a printer using PSI F-235. For this to
work, there must be a SCSI cable from the Noritsu 2611 connected to a SCSI
card on the F-235 host PC. The 2611 should be turned on before the F-235 host
PC is turned on.

If the 2611 is detected by IQueue upon start-up, there will be a green status light
if the PC and 2611 are communicating.




A yellow light indicates a warning for the 2611.

A red light indicates that there is an error on the 2611.

If there is a flashing yellow or red light, the warning or error has not been
acknowledged by the operator. The operator can acknowledge this error by
pressing the yellow or red button. A previously acknowledge warning or error
can also be viewed by pressing the yellow or red button.


                                                                                155
PSI




If the 2611 is connected but the green light does not appear, the PC may have
been powered on before the lab or the SCSI cable may not be fully connected.
 Power down the Pakon system, check the connection, restart the PC, and then
restart PSI and IQueue.




Printing to the 2611
Printing to the Noritsu 2611 requires that the printer be set to "AUX2" mode and
IQueue II be set to print to the mini lab.

AUX2 Mode

If the AUX2 channel is configured on the 2611 already, it is probably channel 13.


To create this AUX2 mode:

   1. Press "Form" on the 2611.
   2. Go to "13" or a blank channel.
   3. Press "Shift" and "Yes."
   4. Select "Print Form" and hit the "Yes" key.
   5. Set "Print Specification" to "AUX2."
   6. Set "Operation Specification" to "CROP."
   7. Set "Display Specification" to "1 FRAME."
   8. Set "Destination of Image Data" to "VFP."
