1. Changes in this release
FX35
Meta data from Imported DSC image sources (method ImportFromFile) is now persisted to the FX35 exported exif images
Added a new scan option for a premium color path (KPT).  To use the premium color path for Color Negative you must have the premium color path enabler installed.  If the premium color path enabler is not installed and the client sets SCAN_UsePremiumColorPath then the SCAN_UsePremiumColorPath will be ignored.
The standard color path has been changed from KCDFS to a standard color path using Ansel 4.1.
Better color balance, Faster save times, Lens falloff compensation, Automatic contrast adjustment for under exposed images, Less histogram stretching that caused noise in bright areas of the picture.
Added new callbacks at the end of the scan for updating client on progress of order analysis step. The order analysis step occurs after the film drive motor stops and before the client gets the WTP_ProgressComplete.  To see these callbacks, the client must scan with the SCAN_UseOrderAnalysisCallbacks option set.
New save interface added that includes new methods for adjusting pictures black and white effect and saturation adjustment
Track test as run by Calibration Wizard (CW) is modified to better handle the latest lot of DX sensors.  Older versions of CW(and FX35 software) may not calibrate the new DX sensors very well (sensors may not detect film but will still read DX).

F135
Setting scanner type to F135 when detecting F135 motor addresses.  This ensures better default values used by CW when EEPROM is blank.  Before CW may have assumed F135P if that was what was in the registry.
Move initial lens position back 700 steps so the zero limit switch on the 135 focus fixture can be moved forward 700 steps and thus prevent the lens from catching on the lens stand during calibration.  When upgrading a CW station from 2.4 to 3.0, the zero limit switch for the lens stepper must be moved forward 700 steps.
Now calling bResetAllPicErrors before each scan.  Before, once the scanner reported an error during a scan, it would continue to be reported even though it was cleared unless the client called resetstatusled, ForceCorrections, tracktest, or changed some scan settings that caused a corrections to occur.

F235
F335
PTS
Added a few new advanced features.
Read in both open gate and scan duty cycles. Used open gate for display and scan gate for power calculation.
Set pass for DX reads to 60%.
Four channel save on a 135/135Plus now works.  In 1.2 it did not.
