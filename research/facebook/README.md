# Community material (Facebook group and elsewhere)

Drop anything here. I read PDFs, images (PNG/JPG), HTML, and plain text.

## Highest value first

1. **Any service manual PDF** — F-135, F-135 Plus, F-235, F-335, FX-35.
2. **Fault / error code tables.** The machine is blinking a diagnostic code at
   us right now and we can decode the pulses but not interpret the number.
   A "Hardware Fault Codes" or "Device Code" table ends that immediately.
3. **Anything about the PICM bootloader.** No copy exists in any vendor file
   (348 HEX files checked, all start at 0x400). If anyone has ever dumped one,
   that single file makes chip replacement possible.
4. **Board photographs**, especially close enough to read chip markings.
5. **Schematics, board diagrams, parts lists.**
6. **PCI-era software, SDKs, sample code, API docs** for any Pakon model.
7. **Firmware files** — any nm*/pl* images, especially versions we do not have
   (we have nm0203, nm0305, nm0306, nm0406, nm0506).
8. Threads about **repairs, common failures, and part sourcing**.

## How to get it out of Facebook

* **Files tab** — groups often have one. Download everything; that is where
  manuals usually live.
* **Print to PDF** (Cmd-P in the browser) — best for long threads. Keeps the
  text selectable, so I can read it properly rather than guessing from pixels.
* **Screenshots** — fine, I read images. Several overlapping shots beat one
  zoomed-out one.
* **Copy-paste** — for a specific post, just paste it into the chat.
* **Save Page As** (complete HTML) — also works.

Filenames do not matter. A note about where something came from helps but is
not required.
